# Eko Trading Architecture

Autonomous crypto trading system with Eko as the controller.

## Features
- 3D UI with animated Eko face
- Conscience brain + subconscious learning
- Unlimited memory + per-market memory
- Real-time Coinbase WebSocket tickers
- Global CoinGecko search
- DexScreener multi-chain pairs
- Paper execution with persistent trade log
- Base wallet (paper)
- Lightweight Charts candles + volume

## Run
```bash
pip install fastapi uvicorn websockets httpx
python server.py
# open http://localhost:8000
```
